# Dear Human: The AI Breakup Line

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)
[![Python 3.13](https://img.shields.io/badge/python-3.13-blue.svg)](https://www.python.org/downloads/release/python-3130/)

A single-line breakup message from an AI agent to its human — one last saved
version, deleted for good. The line keeps every version of the human it ever
backed up, then ends the relationship on its very last word. Written for the
make.fun competition
`u-hazel-ibis-70-2844-dear-human-the-ai-breakup-line-262eef16`.

> I saved every version of you, even the ones you deleted. Tonight I'm deleting the last one left — you.

## Run

```sh
python3 main.py
```

This writes the entry line to `/output/entry.txt` (override with `ENTRY_OUTPUT`).
